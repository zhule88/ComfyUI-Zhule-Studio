

# ComfyUI-Zhule-Nodes

> 给 ComfyUI 装上「中文词库 + 图片图库 + 画师选择器」的一体化工具箱，让你告别手敲英文提示词。

这个插件为 ComfyUI 提供三块核心能力：

- **中文提示词词库**：网页里点卡片选词，中文看着选，自动拼成英文提示词喂给模型；词条可编辑、删除、配参考图，还支持**负面词、排除词、静音**三类精细控制
- **图片图库**：出图自动归档，网页浏览、筛选、打标签、找图一键还原工作流
- **画师选择器**：节点面板里直接搜索、收藏、随机挑画师，画风 tag 自动生成

另外附带一批实用小节点（随机采样参数、LoRA 加载、文本拼接/替换、概率门控等），全部集中在 `Zhule` 分类下。

如果你是刚接触 ComfyUI 的新手，跟着下面的教程走，5 分钟就能上手。

---

## 一、安装

1. 把 `ComfyUI-Zhule-Nodes` 整个文件夹放进 ComfyUI 的 `custom_nodes` 目录
2. 完全关闭 ComfyUI，重新启动
3. 启动完成后，节点菜单里会出现 `Zhule` 分类

> 不需要额外安装任何依赖，开箱即用。

## 二、中文提示词词库（推荐先看这个）

### 2.1 打开词库

在画布上添加 **`ZhuleStudio`（提示词管理器）** 节点，点击节点上的「词库」按钮即可打开词库页面；也可以直接在浏览器访问 `http://127.0.0.1:8188/zhule_studio`。

打开后就是词库界面（见下图），提示词按分类整理成卡片，点击就能选中。

![词库界面](examples/参考图2.png)

### 2.2 词库分类

推荐使用以下十二大类结构，覆盖常用出图要素。注意：首次运行只会自动建立空库（仅建表、不含任何词条），下列分类与词条需在界面中自行建立或通过词库文件导入：

| 分类 | 内容 |
|------|------|
| 角色 | 角色本体，按作品 → 地区分组，词条只含身份与发色 |
| 神态 | 表情、情绪、眼神（开心、害羞、魅惑等） |
| 服装 | 日常、校园、泳装、内衣、睡衣、正装礼服、运动、民族传统、冬装等 |
| 姿势 | 全身（站立 / 坐蹲 / 躺卧 / 倚靠 / 舒展 / 魅力）与局部（手部 / 腿部 / 嘴部） |
| 环境 | 室内、半室外、室外场景 |
| 构图 | 景别、机位角度、朝向视线（身体朝向 / 头部朝向 / 眼神） |
| 发型 | 基础发型、刘海／侧发、发质／状态、扎发／编发 |
| 配饰 | 按**佩戴部位**分组：头部 / 面部 / 耳部 / 发部 / 颈部 / 手部 / 腿足 / 背部·全身 |
| 身材 | 萝莉 / 少女 / 成女 / 熟女 / 高挑等体型 |
| 主题 | 校园、沙滩、冬日雪景、异世界、古风仙侠等成套主题 |
| 杂项 | 纹身、附着物、环境细节等零散要素 |
| 一次性 | 临时用、不想归类的词条，随用随删 |

**配饰的划界规则**：脱掉衣服后仍能单独戴在身上的，进「配饰」；必须依附在衣服上才成立的，留在「服装」。所以套装句（如「JK 制服配乐福鞋」）整句留在服装，不拆件。

配饰八个部位细分：

| 部位 | 子类 |
|------|------|
| 头部 | 帽子、角、兽耳、头巾·头纱（兜帽随衣服走，留在服装） |
| 面部 | 眼镜、墨镜、面具·面罩、眼罩 |
| 耳部 | 耳环、耳钉、耳夹、耳机 |
| 发部 | 束发件、环绕件、夹持件、冠冕、造型装饰（按佩戴方式分，不按造型图案分） |
| 颈部 | 项链、颈圈、领带、领巾、围巾、项圈、其他颈饰 |
| 手部 | 手套、戒指、手链、袖扣、指甲 |
| 腿足 | 袜子、腿环、绑带、鞋 |
| 背部·全身 | 翅膀、披风·披肩、尾巴 |

「颈圈」收装饰向（蕾丝、丝带、铃铛），「项圈」收束缚向（锁链、皮革、刑具），两者不混。

**同类词条不做配色枚举**：镂空、纹样、配色属于变量，一条主词条 + 形容词叠加即可，不为每种组合单开词条。

分类和词条都可以在词库网页里直接增删改，不需要碰任何文件。层级不限深，可以自己往下继续建子类（如 `角色 → 原神 → 璃月 → 某角色`）。

分类只是**组织方式**，选中后拼进提示词的只有叶子词条的内容；父级分类本身不产出任何文本。

### 2.3 怎么用

1. 在 ComfyUI 画布上添加 **`ZhuleStudio`（提示词管理器）** 节点
2. 节点上有一个「ID」输入框，随便填一个名字（比如 `my_prompt_1`），**必须手动填写且保证各工作流间唯一**
3. 点击节点上的「词库」按钮打开词库网页，在顶部找到对应的 ID，点开它
4. 在词库里点选想要的提示词卡片，选中的词会实时同步到画布节点上
5. 点「生成」，节点会直接输出正面和负面提示词给模型

> 词库网页里选词后，画布上对应节点会实时更新，不需要手动复制粘贴。

### 2.4 词条管理

- **编辑词条**：点击卡片弹出编辑面板，共五个字段——**名字 / 英文提示词 / 中文说明 / 负面 / 排除**，每个字段都是一个可折叠抽屉，开合状态自动记住
- **删除词条**：编辑面板右上角红叉或卡片删除按钮即可删除，删错可随时恢复
- **免确认开关**：在设置面板里关掉「删除时弹出确认框」后，删除词条不再弹确认，操作更顺滑
- **参考图**：每张词条卡片可以上传多张参考图（优先展示），放大查看器里可以左右切换、随机跳转
- **遍历补图**：词库页提供「遍历模式」，按当前参考图最多的词条为基准，自动补跑生成任务，集中把一批词条的参考图补齐
- **跳转图库**：词条卡片上点击进入详情，可直接跳转到图库并按该词条过滤出相关出图，方便对比参考图与真实成图

### 2.5 负面词、排除词与静音

这三个字段让词条不只是一段死文本，而是能互相配合：

| 字段 | 作用 | 写法 |
|------|------|------|
| 负面 | 该词条被选中时，内容并入**本次的负面提示词**输出 | 多条用逗号分隔 |
| 排除 | 只删「**别的**词条」产出的提示词段，**不删自己** | 多条用逗号分隔；按逗号段匹配，段内任一词命中即整段排除 |
| 静音 | 不参与遍历、随机、单次随机等**自动选词**，手动点选仍然可用 | 卡片左侧静音按钮一键切换 |

使用要点：

- **排除词单侧书写**：A 与 B 互斥时，只在其中一方写排除即可，不要两边对称写，否则会互相清空
- 卡片上会显示 `负面` / `排除` 角标，一眼看出哪些词条带附加配置
- 被静音的词条默认仍然显示，可在设置里打开「隐藏被静音的提示词」让它们暂时从列表消失（数据不删，关掉开关即回来）

## 三、图片图库

### 3.1 自动归档

用插件自带的 **`ZhuleSaveImage`（保存图片）** 节点出图，图片会自动保存到 ComfyUI 的 `output/zhule_studio/zhule_img` 文件夹，按序号自动命名（`zhule_0001.png`）；保存、删图、打标签都会即时同步图库，不需要额外手动刷新。

### 3.2 打开图库

在画布上添加 **`ZhuleStudio`（提示词管理器）** 节点，点击节点上的「图库」按钮即可打开图库页面。若节点已填写 ID，图库会按该 ID 自动过滤出本节点的出图。

![图库界面](examples/参考图3.png)

### 3.3 图库能做什么

- **浏览**：分页浏览所有出图，缩略图按需加载；支持拖动框选 / Ctrl+点击 多选
- **卡片显示项**：文件名 / 时间 / 模型名 / 标签可在设置里逐项开关，卡片操作图标固定在右上角，不压字
- **筛选**：按模型、LoRA、标签筛选图片；顶部**外部过滤区**列出已选标签条，可随时增删，三列筛选列可独立隐藏
- **详情**：点击图片查看大图，能看到这张图的模型、LoRA、提示词、标签等信息
- **详情标签联动筛选**：详情里点击提示词标签（左键）会把它放入左侧筛选区并立即启用，直接筛出同一词条的其它出图；右键该标签则打开词条编辑弹窗
- **标签关联图数**：外部过滤区（筛选区已放置的标签）与标签编辑面板里的每个标签右侧显示该标签一共关联了多少张图，直观看出哪些词条是主力；**图片详情里的标签不显示数字**。不需要可在设置「图库详情标签 → 标签关联图数角标」里关闭
- **还原工作流**：详情页把工作流拖回画布，就能一键还原这张图的生成参数，方便复刻和微调
- **打标签**：给图片手动添加词库词条标签或自定义标签（自定义标签支持 `/` 层级路径，如 `角色/绝区零/妮可`，多个用英文逗号分隔）
- **删除**：单张删除或批量删除均有确认弹窗（同样遵循免确认开关），删除会同时移除图片文件与缩略图
- **硬链接导出**：把选中的图片以硬链接平铺导出到独立子文件夹，几乎不占额外空间（需与图库在同一磁盘分区）
- **刷新索引**：若文件被外部改动导致列表和磁盘不一致，点「刷新索引」重建即可

## 四、自定义标签与标签配色

### 4.1 自定义标签

- 标签以**层级树**形式管理：**父级只是可展开的分组容器，叶子才是真正的标签**
- 在所有图片相关界面（详情区、外部过滤区、编辑面板、词库页）标签直接**平铺叶子名**展示，简洁不嵌套
- 在标签树面板里**右键标签可删除**，删除有确认弹窗（遵循免确认开关）

### 4.2 标签配色

设置面板里可配置标签颜色，支持两级：

- **简单模式（simple）**：全局一套规则——「异色」按随机种子散列出不同颜色，或「同色」统一用一种颜色
- **分区模式（complex）**：图片详情 / 筛选区域 / 编辑面板 / 词库分类各自独立取色，互不影响

此外：

- **异色随机种子**：可修改随机种子让整套标签颜色重新洗牌
- **同色取色**：同色模式下可指定具体颜色
- **主题与边角**：标签可选「深色 / 浅色 / 描边」三种主题，边角圆润度也可调；换种子时设置面板里的演示块会跟着联动，所见即所得

## 六、其他实用节点

`Zhule` 分类下还附带这些常用小工具：

| 节点名称 | 用途 |
|----------|------|
| `ZhuleStudio` | 提示词管理器：CLIP + 全局 ID + 前置/负面提示词，词库/图库入口，输出正面、负面两组 CONDITIONING |
| `ZhuleSaveImage` | 保存图片并自动归档进图库（可选自定义标签输入） |
| `ZhuleCheckpointLoader` | 加载主模型，支持 random / fixed / manual 三种模式，额外输出模型名、cfg、steps、采样器、调度器供下游使用 |
| `ZhuleLoraLoader` | 加载 LoRA，支持权重与开关；自动输出训练词供提示词使用 |
| `ZhuleLatentSize` | 一键设置常用出图尺寸（1:1、3:2、2:3、4:3、16:9、9:16），支持完全随机 / 随机横屏 / 随机竖屏 |
| `ZhuleTextConcatenate` | 拼接多路文本，最多 16 路，可自定义分隔符、自动去空/去首尾空格 |
| `ZhuleTextReplace` | 对文本做查找替换，支持正则表达式与捕获组，输出替换结果与替换次数 |
| `ZhulePass` | 条件开关：条件为真输出原文本，为假输出空字符串 |
| `ZhuleProbability` | 概率开关：按百分比随机保留或丢弃文本，适合随机抽词；同时输出是否通过 |

## 七、设置面板

点页面右上角齿轮打开，分组可折叠，状态自动保存。

**通用设置**（对所有页面生效）

| 选项 | 说明 |
|------|------|
| 删除时弹出确认框 | 关闭后删除词条、图片都不再弹确认 |
| 图片上的图标大小 | 小 / 中 / 大 / 特大 四档 |
| 隐藏被静音的提示词 | 开启后词库列表不展示静音词条，数据保留 |
| 标签主题 / 边角 / 颜色 | 见上一章 |

**图库设置**

- 卡片显示项：文件名、时间、模型名、标签逐项开关
- 标签关联图数角标：关掉后筛选区与编辑面板不再显示数字
- 筛选列：模型 / LoRA / 标签三列可独立隐藏
- 时间格式；数据库重建入口（仅排障用，正常使用无需触发）

**词库设置**

- 选中子类自动关联父类：点了子类卡片会把父类一并选上
- 去中文清理：扫描英文提示词文件，清掉误混进去的中文字符（中文文件自动跳过）

## 八、常见问题

**Q：网页打不开？**
确认 ComfyUI 已经启动，并且端口是默认的 8188。如果改了端口，把网址里的 8188 换成你的端口。

**Q：词库选词了，画布节点没变化？**
检查节点上的「ID」是否填写，且和词库网页顶部选的 ID 一致。改完 ID 后建议刷新一下网页。

**Q：图库看不到新出的图？**
`ZhuleSaveImage` 保存的图会自动入图库；如果文件是被外部工具改动的，点图库右上角的「刷新索引」按钮，等提示重建完成即可。如果还不行，先 Ctrl+F5 强制刷新浏览器页面。

**Q：画师选择器里没有我想找的画师？**
画师名单支持自行扩充，按插件自带名单文件的格式添加即可。

**Q：词库里有些词条找不到了？**
先看设置里的「隐藏被静音的提示词」是否开着——开启时静音词条不显示但数据仍在，关掉开关就回来。

**Q：想让两个词条互斥，别一起出现？**
用「排除」字段：只在一方写就行，写"不要的那个词"对应的英文段，会在该词条被选中时清掉别的词条里命中的段；两边都写会互相清空。

**Q：保存的图片去哪了？**
固定保存在 ComfyUI 的 `output/zhule_studio/zhule_img` 文件夹，文件名形如 `zhule_0001.png`。
